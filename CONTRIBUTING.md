# Как внести вклад

Спасибо за интерес к проекту. Ниже — правила, которые помогают держать кодовую
базу предсказуемой.

## Разработка

1. Форкните репозиторий и склонируйте его.
2. Создайте ветку от `develop`:

   ```bash
   git switch develop
   git pull
   git switch -c feature/kratkoe-nazvanie
   ```

3. Установите зависимости:

   ```bash
   make dev
   ```

4. Внесите изменения и проверьте их:

   ```bash
   make test
   make lint
   ```

5. Зафиксируйте изменения и откройте pull request в `develop`.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | Стабильная версия, готовая к деплою |
| `develop` | Интеграция готовых изменений |
| `feature/<название>` | Новая функциональность |
| `fix/<название>` | Исправление ошибки |

Прямые коммиты в `main` и `develop` не приветствуются: изменения попадают туда
через pull request.

## Коммиты

Используется [Conventional Commits](https://www.conventionalcommits.org/):

```text
feat: добавить команду статистики
fix: не терять историю при повторном подключении
docs: описать обновление базы знаний
test: покрыть разбор ответа GigaChat
chore: обновить зависимости
```

Сообщение — в повелительном наклонении, до 72 символов в первой строке.

## Код

- Python 3.10+, аннотации типов, `from __future__ import annotations`.
- Стиль проверяется `ruff` (line-length 100).
- Бизнес-логика — в `alina.py`, интеграции — в отдельных клиентах, конфигурация — в `config.py`.
- Новые внешние API оборачивайте клиентом и покрывайте тестами с подменой HTTP.
- Секреты — только через переменные окружения и `.env`. В коде, тестах, логах и
  скриншотах ключей быть не должно.

## Тесты

- Тесты не должны обращаться к реальным VK и GigaChat.
- На каждое исправление — регрессионный тест.
- Запуск: `make test` или `PYTHONPATH=src python -m unittest discover -s tests -v`.

## База знаний

- Факты только с официального сайта Zerocoder, с ссылкой `Источник:`.
- Не добавляйте непроверенные цены, скидки и обещания трудоустройства.
- Проверяйте поиск: `PYTHONPATH=src python -m alina_bot.knowledge_base "вопрос"`.
